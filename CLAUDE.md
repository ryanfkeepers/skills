# Skills Repo

Personal Claude Code skills distributed as a plugin (`keepers`).

Adding a new skill: see the `add-skill` skill.

## Installation

Run these as two separate commands:

```
/plugin marketplace add ryanfkeepers/skills
```
```
/plugin install keepers@keepers
```

Skills are namespaced: `/keepers:skill-name`

## Local testing

```bash
claude --plugin-dir ./
```
